# YelpCamp
An individual take on Colt Steele's Web Development Bootcamp that takes everything a step further. 

## Document ToC
- **ARCHITECTURE.md** showcases the overall architecture of the system.
- **ERROR_HANDLING.md** details the types of errors encountered and the causes for these errors.
- **API.md** lists out the API endpoints.
- **AUTH.md** discusses the hand-rolled auth decisions taken.
- **ADR.md** tracks architectural decisions made during the development of the system.
